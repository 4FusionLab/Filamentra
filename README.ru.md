## Знакомьтесь: Filamentra

**Filamentra** — будущий аддон для Autodesk Fusion от **4FusionLab**. Он поможет находить цвета и визуальные характеристики реальных филаментов для 3D-печати и добавлять их в текущую модель.

Вместо генерации и распространения файлов `.adsklib` проект предполагает собственную палитру с каталогом филаментов. Пользователь выбирает производителя, линейку и цвет, а затем устанавливает нужный Appearance непосредственно в открытый проект.

### Как это будет работать

1. **Найти** производителя, линейку и цвет в отдельной палитре Fusion.
2. **Посмотреть** название продукта, оттенок, тип поверхности и источник данных.
3. **Установить** Appearance в текущую модель без изменения геометрии.
4. **Применить** установленный материал к выбранной геометрии по желанию.
5. **Повторно использовать** ранее установленный Appearance без дубликатов.

### Планируемые возможности

| Направление | Что планируется |
| --- | --- |
| Каталог филаментов | Производитель → линейка → цвет, поиск и фильтры |
| Внешний вид | Приближённое отображение матовых, глянцевых, шелковистых, полупрозрачных и композитных пластиков |
| Установка в модель | Создание Appearance непосредственно в активном проекте Fusion |
| Установленные материалы | Определение уже добавленных Appearance и защита от дублирования |
| Обновление каталога | Версионируемые данные и метаданные через GitHub |
| Работа без сети | Локальный кеш ранее загруженного каталога |

**Это цели проекта, а не готовые функции.** Реализация зависит от проверки актуального Autodesk Fusion API.

## Статус

🚧 **Планирование / начало разработки.** Готовой версии аддона и проверенной реализации для Fusion пока нет.

Первый milestone — небольшая палитра внутри Fusion, устанавливающая один тестовый Appearance в активный проект, с проверкой после сохранения и повторного открытия модели. Только после этого будем расширять каталог.

План этапов: [ROADMAP.md](docs/ROADMAP.md).

## Appearance, а не физический материал

Filamentra предназначена для **визуального предпросмотра при моделировании**. Она не заменяет достоверные физические свойства материалов для прочностных расчётов, симуляций или производственной сертификации.

Цвета и типы поверхности будут приближёнными: на итоговый вид печати влияют экран, освещение, ориентация слоёв и свойства конкретной катушки. По возможности каталог будет указывать первоисточник данных.

## Немного мифологии мастерской

**Филаментра** — богиня филаментов, хранительница бесконечных нитей всех оттенков и фактур. Она помогает мастерам увидеть будущий цвет изделия до того, как принтер уложит первый слой.

В авторской мифологии **4FusionLab** её спутники — **[Perfora](https://github.com/4FusionLab/Perfora)**, богиня отверстий, **[Selectra](https://github.com/4FusionLab/Selectra)**, богиня выбора, и **[Planara](https://github.com/4FusionLab/Planara)**, богиня плоских миров.

**Другие инструменты 4FusionLab:** [Ejix — извлечение объёмов](https://github.com/4FusionLab/Ejix) · [RuEn — горячие клавиши](https://github.com/4FusionLab/RuEn)
