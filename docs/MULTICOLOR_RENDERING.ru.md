# Рендерер многоцветного предпросмотра — экспериментальная версия

[English](MULTICOLOR_RENDERING.md)

Filamentra содержит **автономный генератор PNG** для отображаемых производителями образцов RGBA и **небольшой экспериментальный адаптер Fusion API**. Полный сценарий аддона ещё не проверен в Autodesk Fusion и не готов к выпуску.

## Цели и режимы

- Solid: один проверенный цвет производителя; используется напрямую `Appearance.color` (здесь не реализовано).
- Multicolor / подобие коэкструзии: создание резких **цветовых полос в UV** по двум или более опубликованным образцам.
- Gradient / rainbow: создание плавных **UV-градиентов** между опубликованными образцами RGBA.

Все узоры — **предпросмотр в UV-пространстве**, а не физическая симуляция экструзии филамента. Распределение оттенков на напечатанной детали зависит от оси печати, траекторий слайсера, подачи филамента, положения катушки, расположения пигментов при экструзии и геометрии. Filamentra не может вывести эти данные только из образцов.

Для записей с несколькими цветами необязательный объект `rendering` управляет предпросмотром по умолчанию. При его отсутствии генератор выбирает `uv_bands` для `color_mode="multicolor"` и `uv_gradient` для `color_mode="gradient"`. В будущем интерфейс сможет менять направление и число повторов во время выполнения. Источник данных рендеринга всегда должен быть `filamentra_estimate`.

## Автономная генерация PNG

    from filamentra.texture_generator import render_to_cache

    shade = {
        "color_mode": "multicolor",
        "rgba_swatches": ["#3D3D3FFF", "#EC4235FF"]
    }
    texture_path = render_to_cache(shade, "/tmp/filamentra-cache", 512, 512)

Функция использует только стандартную библиотеку Python (без PIL, NumPy и внешних сетевых запросов), записывает детерминированный RGBA PNG и кеширует его по хешу содержимого. Сохраняются все каналы образца производителя, включая alpha; непрозрачность отображаемого образца **не** равна измеренному объёмному пропусканию света. Сейчас градиент интерполирует значения каналов в кодированном sRGB; это алгоритм предпросмотра, а не спектральное смешение.

## Адаптер Fusion API — только ручной тест

    from filamentra.fusion_appearance import install_preview_appearance

    # Требуются существующий adsk.fusion.Design и созданный texture_path.
    appearance = install_preview_appearance(
        design,
        "Filamentra | esun/pla-matte-dual/black-red",
        texture_path,
        roughness=0.86
    )

Адаптер вызывает `Design.appearances.add`, подключает `Appearance.colorTexture`, затем шероховатость. Он намеренно не назначает Appearance геометрии, не обрабатывает постоянные идентификаторы и не предоставляет палитру. Целевая версия API — Fusion за июль 2026 года и новее.

## Проверка и следующие шаги реализации

Запустите тесты без Fusion:

    python -m unittest discover -s tests -v

Затем вручную проверьте Autodesk Fusion на Windows и macOS на кубе, цилиндре и криволинейной детали:

1. Создайте внешний вид без изменения геометрии.
2. Проверьте направление UV-проекции, швы и повторение для примеров с двумя и четырьмя цветами.
3. Выполните рендер в окне Design и в рабочей среде Render.
4. Сохраните и повторно откройте модель; убедитесь, что встроенная текстура и шероховатость сохранились.
5. Прежде чем заявлять визуальную калибровку, проверьте реальные напечатанные образцы при контролируемом освещении.

**Не реализовано:** мост HTML Palette, элементы управления UV-проектором, пресеты направления для геометрии, обнаружение дубликатов, пользовательский поворот, Apply to Selection, загрузки релизов каталога и проверенная физическая оптическая симуляция. Позиционирование градиента по слоям требует данных слайсера или принтера и явно не входит в задачи текущего генератора текстур.

Исходные данные и подсказки для предпросмотра находятся в [Filamentra-DataSource](https://github.com/4FusionLab/Filamentra-DataSource). Рендеринг и интеграция с Fusion находятся в этом репозитории.
